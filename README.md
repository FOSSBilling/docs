# FOSSBilling Docs

Source for [FOSSBilling documentation](https://docs.fossbilling.org), built with Astro, Starlight, and Markdoc.

## Local Development

Use Node.js 26.12 or later in the 26.x series to match CI.

```bash
npm ci
npm run dev
```

Open [localhost:4321](http://localhost:4321). Run `npm run format:check`, `npm run check`, and `npm run build` before opening a PR against `main`.

If GitHub requires approval to run CI on a fork PR, a maintainer can select **Approve and run workflows**.

## Editing Content

- Write `.mdoc` pages in `src/content/docs/` with `title` and `description` frontmatter. Name section overviews `index.mdoc`.
- Check the sidebar in [`astro.config.ts`](./astro.config.ts) when adding pages. In autogenerated sections, use `sidebar.label` or `sidebar.order` to override the label or position.
- Use root-relative internal links with trailing slashes. When moving a page, update its links and add a rule to `public/_redirects` if the old URL needs a [redirect](https://developers.cloudflare.com/workers/static-assets/redirects/).
- Put documentation images in `src/assets/` and reference them with relative paths. Get logos and browser icons from the [branding manifest](https://branding.fossbilling.org/manifest.json).

## Deployment

[CI](./.github/workflows/ci-cd.yml) builds the site with Astro and the Cloudflare Vite plugin. The shared Cloudflare workflow deploys the prebuilt output to production for successful `main` builds and to previews under `docs.fossbilling.foo` for successful builds on other branches in this repository. [Cloudflare Events](./.github/workflows/cloudflare-events.yml) posts preview links on PRs and removes previews when same-repository PRs targeting `main` close. See [`cloudflare.config.ts`](./cloudflare.config.ts) for Worker settings.

For fork PRs targeting `main`, successful CI publishes a preview of the current head commit and posts its link on the PR. If the build artifact has expired after 14 days, rerun all jobs in the PR's CI/CD run to regenerate it. Closing the PR removes the preview.
